# First Principles Thinking — Acceptance Checklist

- [ ] The problem frame is stated as a single concrete sentence describing a real, current project situation.
- [ ] Every assumption the team holds about the problem is captured in the assumption inventory.
- [ ] Each assumption is classified as Verified, Unverified, or Convention with a stated rationale.
- [ ] The bedrock section lists only irreducible, confirmed facts — no unverified assumptions appear as first principles.
- [ ] At least two alternative framings are produced from the bedrock alone, without reintroducing unverified constraints.
- [ ] Each alternative framing is evaluated against feasibility, stakeholder alignment, and estimated effort.
- [ ] A recommended path is stated with a clear rationale; if no path is ready, the missing information is named explicitly.
- [ ] The output cites the canonical First Principles reference URL (`https://plato.stanford.edu/entries/aristotle-logic/`).
- [ ] The "Source consulted" section records which mode was used (offline or online) and does not include fabricated quotations or page numbers.
- [ ] The facilitation dialogue is in the language at `language.communication`, and the saved artifact is in the language at `language.output` (falling back to `language.communication` if `language.output` is absent or empty).
- [ ] The artifact is saved to `docs/pm-kit/outputs/brainstorming-first-principles-thinking/<slug>.md` and begins with the three-line provenance header.

> Mark **PASS** or **FAIL**. On **FAIL**, return to the skill with notes.
