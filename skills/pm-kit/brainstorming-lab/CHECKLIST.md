# Brainstorming Lab — Acceptance Checklist

- [ ] All five diagnostic questions were asked and answered before any strategy was recommended.
- [ ] The strategy recommendation draws from the curated 20 strategies only (unless the user explicitly requested the full deck).
- [ ] The rationale connects the recommended strategy to the specific diagnostic answers — it is not a generic description of the strategy.
- [ ] If a secondary recommendation is included, its rationale explains when or why it is preferable to or complements the primary recommendation.
- [ ] The hand-off step names the next skill to invoke using its exact kebab-case identifier.
- [ ] The output cites the canonical brainstorming reference URL (`https://en.wikipedia.org/wiki/Brainstorming`).
- [ ] The "Source consulted" section records which mode was used (offline or online) and does not include fabricated quotations or page numbers.
- [ ] The facilitation dialogue is in the language at `language.communication`, and the saved artifact is in the language at `language.output` (falling back to `language.communication` if `language.output` is absent or empty).
- [ ] The artifact is saved to `docs/pm-kit/outputs/brainstorming-lab/<slug>.md` and begins with the three-line provenance header.

> Mark **PASS** or **FAIL**. On **FAIL**, return to the skill with notes.
