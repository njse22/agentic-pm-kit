- [ ] At least 3 parameters are identified, each with 2 or more discrete options.
- [ ] The Morphological Box is fully populated — no placeholder values remain unfilled.

- [ ] At least 2 combinations are selected from the consistency-checked matrix, each with a written rationale.

- [ ] The recommended path forward names an owner and a target date for the next action.
- [ ] The output cites the canonical Morphological Analysis reference URL (`https://www.swemorph.com/ma.html`).
- [ ] The "Source consulted" section records which mode was used (offline or online) and does not include fabricated quotations or page numbers.
- [ ] The facilitation dialogue is in the language at `language.communication`, and the saved artifact is in the language at `language.output` (falling back to `language.communication` if `language.output` is absent or empty).
- [ ] The artifact is saved to `docs/pm-kit/outputs/brainstorming-morphological-analysis/<slug>.md` and begins with the three-line provenance header.
