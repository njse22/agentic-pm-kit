# Question Storming — Acceptance Checklist

- [ ] The challenge frame is stated in a single sentence and represents the original, unmodified problem statement from Step 1.
- [ ] The question inventory contains at least two questions in each of the four categories (Clarifying, Probing, Challenging, Re-framing).
- [ ] Each question is a genuine question — no statements, answers, or justifications appear in the question columns.
- [ ] Exactly three Top-3 Priority Questions are identified with a rationale for each.
- [ ] Each Top-3 Priority Question has an assigned owner (role or name) and an answer-by date or sprint.
- [ ] The output cites the canonical Question Storming reference URL (`https://rightquestion.org/what-is-the-qft/`).
- [ ] The "Source consulted" section records which mode was used (offline or online) and does not include fabricated quotations or page numbers.
- [ ] The facilitation dialogue is in the language at `language.communication`, and the saved artifact is in the language at `language.output` (falling back to `language.communication` if `language.output` is absent or empty).
- [ ] The artifact is saved to `docs/pm-kit/outputs/brainstorming-question-storming/<slug>.md` and begins with the three-line provenance header.

> Mark **PASS** or **FAIL**. On **FAIL**, return to the skill with notes.
