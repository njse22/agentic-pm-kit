# Solution Matrix — Acceptance Checklist

- [ ] The decision question is stated in one sentence and represents a genuine selection among real alternatives.
- [ ] At least two alternatives are present as columns in the matrix; at least three criteria are defined, each independent and observable.
- [ ] Every criterion has an assigned weight; at least one criterion has a weight of 4 or 5.
- [ ] Every cell in the matrix is populated with a raw score and a corresponding weighted score; no cell is blank or contains a placeholder.
- [ ] Score rationales are recorded for each criterion-alternative combination and are grounded in the user's stated reasoning.
- [ ] Weighted totals are computed correctly (weight × raw score summed per alternative).
- [ ] A sensitivity check is documented if the user requested one, or explicitly noted as not performed.
- [ ] A recommendation names the top-ranked alternative, at least one runner-up with the criterion on which it outperforms the winner, and a next action with an owner and target date.
- [ ] The output cites the canonical Decision Matrix reference URL (`https://en.wikipedia.org/wiki/Decision_matrix`) and the "Source consulted" section records the mode used (offline or online) without fabricated quotations or page numbers.
- [ ] The facilitation dialogue is in the language at `language.communication`, and the saved artifact is in the language at `language.output` (falling back to `language.communication` if `language.output` is absent or empty).
- [ ] The artifact is saved to `docs/pm-kit/outputs/brainstorming-solution-matrix/<slug>.md` and begins with the three-line provenance header.

> Mark **PASS** or **FAIL**. On **FAIL**, return to the skill with notes.
